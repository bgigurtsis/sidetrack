# Sidetrack was renamed Kirby

Use the current [kirby-luna skill](../kirby-luna/SKILL.md). It delegates bounded,
independent tasks to native Luna subagents while the main model handles integration
and review. Keep the selected main model unchanged and follow normal permissions.

This compatibility reference is retained for older checkouts. The current installer
installs kirby-luna. Do not invoke the retired sidetrack.py script or assume that an
old CLI instruction authorizes a source transfer. If native delegation is unavailable,
report the limitation and continue permitted direct work.
